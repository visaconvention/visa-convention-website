# Brand Assets — Logo Directory

Place official Visa Convention logo files in this directory.

### Requirements:
- **Primary Logo:** High-resolution vector `.svg` or transparent background `.png` (minimum 1000px wide).
- **Inverted / Dark Background Logo:** White/light variant for use on deep navy (`#102A53`) headers or hero sections.
- **Favicon / App Icon:** Square 512x512px icon featuring the globe-and-plane motif.
- **Brand Colors:**
  - Deep Navy: `#102A53`
  - Signature Red: `#C91D32`
  - Professional Blue: `#2367A4`
  - White: `#FFFFFF`
